# LIFE RPG — функциональная миграция старой версии

Цель: перенести все пользовательские функции из корневого `index.html` (legacy) в `app/` на ветке `mobile-check`, не меняя legacy-версию в `main`.

## Порядок переноса

1. **Сохранность и совместимость данных:** расширить модель состояния, миграции и экспорт так, чтобы новые функции не ломали существующие сохранения.
2. **Основное игровое ядро:** полноценные квесты/привычки/история действий, направления и интерактивное дерево.
3. **Прогрессия:** достижения, титулы, ключевые навыки, практика/мастерство, streak/rest day, level-up.
4. **ИИ:** наставник, диагностика, маршрут, генерация квестов/дерева, выбор и принятие черновиков.
5. **Цели, лор и ритуалы:** полный CRUD, недельный обзор, вечерний ритуал, Markdown.
6. **Сохранение и UX:** undo, backups, import merge/replace, настройки тем, onboarding, справка, haptics.

## Критерии завершения

- Каждая функция из legacy-инвентаризации имеет рабочий аналог в новой версии или явно помечена как сознательно изменённая с сохранением результата для пользователя.
- Нет фиктивных кнопок и UI, который обещает неработающую функцию.
- Локальный режим работает без backend; облако и ИИ показывают честный статус, пока backend не настроен.
- CI: typecheck, tests и production build проходят.
- Legacy `main/index.html` не изменён.
