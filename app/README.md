# LIFE RPG

Мобильная PWA «реальная жизнь как RPG»: квесты, привычки, деревья навыков и числовые цели. Награда выдаётся только за подтверждённый результат. Интерфейс — на русском, тёмная тема по умолчанию, ядро работает без сети, аккаунта и ИИ.

## Почему этот стек

1. **React + TypeScript + Vite PWA** — один production-каркас для iPhone и Android, установка на домашний экран, быстрый холодный старт и ленивая загрузка экранов.
2. **Tailwind + собственные OKLCH-токены** — адаптивные safe-area и tap-target стили, два пресета и тёмная/светлая темы без раздувания UI-зависимостей.
3. **Zustand** — единый стейт игрового ядра без размножения сетевых и локальных моделей; действия выполняются атомарно.
4. **IndexedDB через idb-keyval** — асинхронный офлайн-сейв; предыдущий localStorage-сейв автоматически переносится. Это локальная копия только в текущем браузере.
5. **Hono + tRPC + Drizzle + MySQL** — типобезопасный серверный API, анонимная сессия без регистрации, код восстановления и один облачный сейв на аккаунт.
6. **AI SDK на сервере** — модель Groq проверяется по доступному списку; API-ключ остаётся только на сервере. ИИ возвращает только черновики.
7. **Service Worker + Web App Manifest** — кэш приложения и повторный запуск офлайн. API-ответы намеренно не кэшируются.

## Модули

- `contracts/game.ts` — Zod-схема версии 1, общие типы, XP-таблица, уровни, стадии, локальные даты и streak.
- `src/store/gameStore.ts` — офлайн-ядро: квесты, привычки, XP, цели, лор, импорт и persist в IndexedDB.
- `src/pages/` — пять основных экранов; маршруты загружаются лениво.
- `src/components/game/` — мобильная оболочка, карточки квестов, формы, облако и ИИ-панель.
- `api/save-router.ts` — чтение и синхронизация сейва по `revision + updatedAt`.
- `api/ai-router.ts` — диагностика, дерево, квесты на день и наставник через серверный proxy.
- `db/schema.ts` — анонимные пользователи, хеши кодов восстановления и версионированные облачные сейвы; миграции в `db/migrations/`.
- `public/sw.js` — offline app shell без кэширования `/api/`.

## Модель данных

### Hero

`name, xp, level, streakDays, activityDates, totalCompleted, habitCompletions, bossCompleted`.

Уровень вычисляется от накопленного XP: `floor(sqrt(xp / 100)) + 1`. Титул зависит от уровня, достижения — от реальных порогов.

### Quest

`id, title, type, difficulty, xp, description, completionCriteria, minutes, directionId, skillId, goalId, goalUnits, done, completedAt, fromAi, lastCompletedDate, completionDates, habitStreak, awardedXp, reflection, createdAt`.

Типы: `SIDE`, `MAIN`, `BOSS`, `HABIT`. Сложность: 1–5. `done` и `completedAt` выставляются вместе. Разовые выполненные квесты исчезают из активного списка и остаются в архиве.

### Direction / Skill

Направление: `id, name, description, stage, xp`.

Навык: `id, directionId, parentId, name, xp`. `parentId = null` означает корень. XP от квеста одновременно начисляется герою, направлению и выбранному навыку.

Стадии по XP направления: новичок `<400`, средний `400–1499`, продвинутый `1500–4999`, профи `5000+`.

### Goal

`id, title, horizon, target, current, unit, directionId, createdAt`. Горизонты: до 4 недель, 1–6 месяцев, больше 6 месяцев. Связанный квест увеличивает `current` на `goalUnits`, не превышая `target`.

### Lore / Settings / Save

Лор создаётся после MAIN/BOSS и повышения уровня. Настройки хранят тему, пресет, подтверждение критерия и онбординг.

Облачный сейв: `userId (unique), payload JSON, revision, deviceId, createdAt, updatedAt`. Конфликт разрешается по ревизии и более новому `updatedAt`; локальная копия не удаляется.

## Правила XP, streak и habits

| Тип | Сложность 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|
| SIDE | 20 | 50 | 120 | 280 | 650 |
| MAIN | 80 | 180 | 400 | 800 | 1600 |
| BOSS | 250 | 600 | 1200 | 2500 | 5000 |
| HABIT | 10 | 15 | 25 | 40 | 60 |

- Перед начислением можно требовать подтверждение `completionCriteria`.
- MAIN/BOSS открывают необязательную короткую рефлексию.
- Luck-бонус: вероятность 8%, ещё 20% XP (минимум 5). Это редкая переменная награда, а не основной цикл.
- Привычка возвращается в активные после смены локальной даты. История `completionDates` сохраняется.
- Отметку привычки можно снять только за сегодня; `awardedXp`, прогресс цели, навык и направление откатываются симметрично.
- Серия считается по уникальным датам реальных завершений. Один пропущенный день поглощается; длинный перерыв начинает новую серию.
- MVA: стартовые привычки занимают 10 минут, генератор получает стадию, время и энергию, чтобы не предлагать новичку непосильный квест.

## Авторизация и синхронизация

При первом запуске сервер автоматически создаёт анонимный профиль. Вход и OAuth не нужны. Для переноса прогресса пользователь создаёт код восстановления в разделе «Ещё» и вводит его на другом устройстве. На сервере хранится только SHA-256-хеш кода. Код многоразовый; генерация нового заменяет предыдущий. Потеря кода вместе с устройством означает потерю доступа к аккаунту.

Локальный сейв остаётся доступен офлайн. При наличии сети он синхронизируется с MySQL через Hono/tRPC. При восстановлении на новом устройстве облачная копия принудительно загружается поверх локального пустого профиля.

## ИИ

Режимы: диагностика уровня, дерево навыков, квесты на день и наставник. Все ответы на русском. Квесты и навыки записываются только после явного подтверждения. XP на сервере пересчитывается по таблице, а не принимается на веру от модели.

Ошибки квоты, конфигурации, контента и временной недоступности имеют отдельные русские сообщения. Платёжный вызов автоматически не повторяется. Без ИИ ручное ядро полностью доступно. Провайдер — Groq; задать `GROQ_API_KEY`, `GROQ_MODEL` и при необходимости `GROQ_BASE_URL` в серверном окружении. Не использовать `VITE_` для секретов.

## Запуск и проверка

```bash
npm install
npm run db:push
npm run dev       # http://localhost:3000
npm run check
npm run test
npm run build
npm start
npm run db:generate
```

Проверено: сборка и type-check, 5 unit-тестов прогрессии и деградации ИИ, мобильные сценарии выполнения/отмены привычки, архив разового квеста, создание цели и поднавыка, экспорт JSON, IndexedDB после перезагрузки, офлайн-перезапуск PWA, тёмная и светлая темы, отсутствие горизонтального скролла.

## v1 → v2 и оплата

**v1 (этот прототип):** пять экранов, ручное ядро, IndexedDB, PWA, облачный сейв, ревизии, ИИ-черновики, экспорт/импорт и базовая аналитика показателей.

**v2:** очередь конфликтов по отдельным сущностям вместо snapshot LWW, native-оболочка при необходимости, фоновые push и нативная haptics, расширенная аналитика, совместные боссы, Telegram Mini App как дополнительный канал, нормализованные таблицы для аналитики длинных серий.

**Оплата:** entitlement `free | pro` на сервере, отдельный webhook-провайдер подписок, серверная проверка `pro` для ИИ/облака/аналитики. Клиент хранит только отображаемый статус. При отмене подписки данные остаются доступны для экспорта, а ручное офлайн-ядро не блокируется. Конкретный платёжный провайдер выбирается перед публичным запуском; в прототипе платежи не имитируются.
